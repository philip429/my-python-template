# Reference notebooks (work in progress)

These notebooks are learning notes and experimental examples. 

Some notebooks contain saved outputs, external dataset downloads, Colab-specific
paths, and imports that are not part of the template dependencies (for example,
`palmerpenguins`, `pyreadr`, `kagglehub`, `phik`, and `lightgbm`). Review each
notebook's data requirements and code before running it in a separate environment.

Before promoting a notebook into the template, document its data source and
dependencies, replace local paths with project paths, clear outputs, and verify
it runs from beginning to end in a clean environment.
